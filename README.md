# BuildCalc Android-app

De BuildCalc-webapp (`www/index.html`, gemaakt uit `../html/buildcalc.html`) verpakt met Capacitor.

- `docs/` wordt de GitHub Pages-site: webversie, `versie.json` en de live-updatebundel.
- Live updates: plug-in `@capgo/capacitor-updater` in handmatige modus, zonder abonnement.
- Spraak: `@capacitor-community/speech-recognition`. Lasermeter: `@capacitor-community/bluetooth-le`.
  Bestanden: `@capacitor/filesystem` en `@capacitor/share`.

Zie **STAPPENPLAN.md** voor het bouwen van de APK.
